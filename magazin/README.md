# BEQVA Magazin — isolated launch candidate

Static magazine isolated in `magazin/`. Cloudflare Pages publish directory: `magazin`, no build command. Do not enable the domain, public indexing, or deploy the private preview catalog until launch approval. Existing news site remains unaffected. No third-party scripts, cookies, customer data or product photos. Motion creative is original abstract CSS artwork, not an actual product representation. No public upload of private supplier/reference catalog.

`data/catalog.json` is intentionally empty in the tracked branch. A private preview can replace it only in a separate local copy with `{schema:1,mode:"preview",products:[{id,name,brand,category}]}`. Product checkout links remain disabled in preview. Final feed requires an owner-controlled **published-only** export with per-product `approved:true`, explicit approval for publication, no supplier cost/stock data or product photo rights until verified. A public product link contract is proposed as `https://beqva.de/app/product?product=<id>`; the current app parser only recognizes the preview origin and this path is not yet live. The storefront must provide HTTPS web fallback and association files; Android/iOS signing, browser fallback and cold/warm tests are release prerequisites. Keep production, DNS and apps untouched until separately authorized.

Before launch: verify Impressum/Datenschutz, editorial sources and advertising disclosures; publish only approved product assets, ensure product URL resolves, publish sitemap and setup independent Cloudflare project `beqva-magazin`. The app parser currently allows only 100-character IDs; six existing catalog IDs exceed this limit. The future app parser and web route must share the 160-character contract before any public product links are enabled. Reconfigure automation separately: verified first-party published catalog export + reviewable drafts, not the old RSS news monitor. No scraping, auto-published unverified offers, fabricated sales or reviews.

Run `node --test magazin/test/catalog.test.cjs` from repository root. Preview `python -m http.server 8000 --directory magazin`.
